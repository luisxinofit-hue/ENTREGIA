Aviso de privacidad

ENTREGIA — Verificación de identidad antes de una entrega o alquiler de valor.

Resumen: ENTREGIA utiliza datos personales para atender solicitudes, coordinar y ejecutar verificaciones de identidad, entregar resultados, gestionar la operación del servicio y medir el funcionamiento de sus canales digitales.

1. Responsable y contacto

ENTREGIA coordina el tratamiento de datos asociado a la atención comercial y al proceso de verificación. Para consultas sobre privacidad o solicitudes relacionadas con tus datos personales, puedes comunicarte por WhatsApp al +51 929 131 812.

2. Datos que podemos tratar

  • Datos de contacto y conversación proporcionados por clientes o interesados a través de WhatsApp.
  • Datos necesarios para gestionar pagos, solicitudes e incidencias operativas.
  • Para la persona que será verificada: datos del documento de identidad, imágenes o capturas necesarias para la verificación, datos faciales o biométricos utilizados para la prueba de vida y la coincidencia facial, resultados de las comprobaciones y datos técnicos de la sesión.
  • Datos técnicos de navegación y parámetros de campaña, como página visitada, clics, procedencia publicitaria y eventos de medición.

3. Finalidades

  • Atender consultas y solicitudes de Verificación ENTREGIA.
  • Coordinar el pago y la creación de la sesión de verificación.
  • Ejecutar la verificación de documento, prueba de vida y coincidencia facial.
  • Preparar y entregar el informe ENTREGIA.
  • Gestionar soporte, incidencias, seguridad y trazabilidad operativa.
  • Analizar el desempeño de la web y de campañas publicitarias para mejorar el servicio.

4. Datos biométricos y aceptación

Los datos biométricos utilizados para verificar identidad reciben una protección reforzada. La persona que será verificada debe conocer el proceso y aceptar expresamente su participación antes de iniciar la sesión. ENTREGIA no utiliza la verificación para calificar la conducta, solvencia o confiabilidad futura de una persona.

5. Proveedores que pueden intervenir

Para prestar el servicio, ENTREGIA puede utilizar proveedores especializados de verificación de identidad, comunicación y medición digital. Entre ellos se encuentran Didit para las comprobaciones de identidad, WhatsApp para la comunicación y Meta para funciones de medición publicitaria mediante tecnologías como Meta Pixel.

6. Conservación y seguridad

Los datos se conservan durante el tiempo necesario para cumplir las finalidades informadas, gestionar la operación, atender incidencias o reclamos y cumplir las obligaciones aplicables. ENTREGIA adopta medidas razonables de seguridad para reducir accesos, usos o divulgaciones no autorizadas.

7. Derechos de la persona

Puedes solicitar información sobre tus datos, pedir su actualización o rectificación, solicitar su cancelación cuando corresponda, oponerte al tratamiento en los supuestos aplicables y revocar el consentimiento cuando proceda. Para iniciar una solicitud, contáctanos por WhatsApp al +51 929 131 812.

8. Medición del sitio web

La landing de ENTREGIA puede utilizar herramientas de medición para conocer visitas, clics y acciones realizadas en la página. Esta información se utiliza para evaluar el funcionamiento de la web y las campañas de adquisición.

9. Cambios al aviso

Este aviso puede actualizarse cuando cambie el servicio, sus proveedores o los requisitos aplicables. La versión publicada en esta página será la referencia vigente.
